# Shiplog v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-ruby:subagent-driven-development (recommended) or superpowers-ruby:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Shiplog Rails engine described in `docs/superpowers/specs/2026-10-26-shiplog-v1-design.md`.

**Architecture:** One gem with two isolated engines: `Shiplog::Engine` (public pages, webhook, assets) and `Shiplog::Admin::Engine` (admin). It syncs GitHub over GraphQL into host-DB tables, and LLM drafts go through a host callable. The rules (columns, shipped, change candidates) live in plain Ruby objects under `app/models/shiplog/`, which are tested directly.

**Tech Stack:** Ruby 4.0.9, Rails 8.1.4, PostgreSQL, Minitest, WebMock (tests only), vanilla ES module for drag and drop. No runtime dependency other than `rails`.

**Plan granularity note:** Each task lists its files, the tests to write first (names and assertions), and the code for the parts that are easy to get wrong. Implementers write the remaining code test-first, following the conventions here. Every task ends green (`bin/rails test`, `bin/rubocop`) and with a commit.

**Conventions (all tasks):**
- Run everything from the repo root with Ruby 4.0.9 (mise). The test DB is Postgres on localhost (`shiplog_test`), configured in `test/dummy/config/database.yml`.
- Commit messages use Conventional Commits (`feat:`, `test:`, `chore:`).
- Code style: rubocop-rails-omakase, double quotes, small methods, no comments that restate code.
- Tests: Minitest + fixtures in `test/fixtures/shiplog/*.yml`. GitHub HTTP is stubbed with WebMock, and GraphQL responses live in `test/fixtures/files/github/*.json`. The LLM is a lambda set in the test (`Shiplog.config.rewriter = ->(prompt) { ... }`). `Shiplog.reset_config!` runs in `teardown` (via `ActiveSupport::TestCase` setup in `test/test_helper.rb`).

  belongs_to :repository
  belongs_to :parent, class_name: "Shiplog::Issue", primary_key: :node_id, foreign_key: :parent_node_id, optional: true
  has_many :children, class_name: "Shiplog::Issue", primary_key: :node_id, foreign_key: :parent_node_id

  has_many :entries, as: :subject, dependent: :destroy
  enum :pinned_column, COLUMNS.index_by(&:itself), prefix: :pinned, validate: { allow_nil: true }

  scope :labeled, ->(name) { where("labels @> ?", [ name ].to_json) }

  def public? = labels.include?(Shiplog.config.public_label)
  def open? = state == "open"

  def descendants
    children.flat_map { |child| [ child, *child.descendants ] }
  end

```ruby
class Shiplog::Roadmap
  Item = Data.define(:issue, :entry, :column)

  def initialize(published_only: true) = @published_only = published_only

  def columns
    items.group_by(&:column).then { |g| Shiplog::Issue::COLUMNS.index_with { |c| g.fetch(c, []) } }
  end

  def items
    issues = Shiplog::Issue.open.publicly_labeled.includes(:parent, :entries)
      .order(Arel.sql("position ASC NULLS LAST, github_updated_at DESC"))
    issues.reject { |issue| issue.parent&.public? }.filter_map do |issue|
      entry = issue.entries.find(&:roadmap?)
      next if @published_only && !entry&.approved?
      Item.new(issue:, entry:, column: ColumnResolver.new(issue).column)
    end
  end
end

class Shiplog::Roadmap::ColumnResolver
  def initialize(issue) = @issue = issue

  def column
    @issue.pinned_column ||
      (in_progress? && "in_progress") ||
      (coming_soon? && "coming_soon") ||
      "later"
  end

  private
    def in_progress?
      @issue.assignees_count.positive? ||
        [ @issue, *@issue.descendants ].any? { |i| i.linked_pull_requests.any? { |pr| pr.state == "open" } }
    end

    def coming_soon?
      @issue.milestone_title.present? || @issue.labels.intersect?(Shiplog.config.soon_labels)
    end
end
```
